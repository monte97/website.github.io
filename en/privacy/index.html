    Privacy and Personal Data Policy

    Privacy - Management of Personal Data

    Montelli Francesco processes your data in compliance with the European Regulation (EU) 2016/679 regarding the protection of natural persons with regard to the processing of personal data.

    According to current European legislation on Cookies, all sites are required to inform the user about the use of Cookies present on the site itself.

    Data Controller and Person in Charge of Processing

    The data controller and person in charge of processing the data collected on this site is Montelli Francesco.

    Types of Data Processed

    Navigation Data

    The computer systems and software procedures responsible for the operation of the site acquire, during their normal operation, some data whose transmission is implicit in the use of Internet communication protocols. Montelli Francesco never collects such data in a form that allows user identification.

    This category of data includes:

    • IP addresses or domain names of computers used by users connecting to the site
    • The URI (Uniform Resource Identifier) addresses of the requested resources
    • The time of the request
    • The method used to submit the request to the server
    • The file size obtained in response
    • The numerical code indicating the status of the response given by the server (success, error, etc.)
    • Other parameters regarding the operating system and computer environment of the user

    These data are used exclusively in anonymous form and for statistical purposes related to the use of the site and its proper functioning.

    Data Provided Voluntarily by the User

    The collection of users’ personal data can occur voluntarily through:

    • Sending emails to the addresses listed on the site
    • Submitting electronic forms on the site by users

    Sending an email requires the collection by the Data Controller of the sender’s email address, necessary to respond to the request, as well as any other personal data contained in the communication. The personal data collected through this method will be used by the Data Controller solely to respond to the received email message and for any subsequent related communications.

    Sending forms requesting information involves the collection of information sent through the forms.

    General Information about Cookies

    When you access a website, it or related sites may set or read cookies and/or other identifiers about the browser and/or the device you are using.

    A cookie is a small text file that is stored on the computer of someone viewing a website in order to record certain information regarding the visit as well as to create a system to recognize the user even at later times. Device identifiers, on the other hand, are generated by collecting and processing certain information such as the IP address and/or user agent (browser version, type and version of the operating system) or other characteristics of the device, always for the purpose of linking certain information to a specific user.

    A website can only set a cookie on the browser if the preferences configured for it allow it. It is important to know that a browser can only allow a given website to access the cookies it has set and not those set by other websites: there is no risk to your privacy in this regard.

    Use of Cookies

    This site uses Cookies to make its services simple and efficient for users viewing the pages.

    Types of Cookies Used

    Below are the various types of cookies used by this site depending on the purposes of use:

    Technical Cookies

    This type of cookie allows the correct operation of some sections of the site. They are of two categories:

    • Persistent: once the browser is closed they are not destroyed but remain until a preset expiration date
    • Session: they are destroyed every time the browser is closed

    These cookies, sent always from our domain, are necessary to correctly display the site and in relation to the technical services offered, they will therefore always be used and sent, unless the user modifies the browser settings (compromising the display of site pages).

    Analytical Cookies

    Cookies in this category are used to collect information about site usage. This is anonymous statistical information. This type of cookie collects anonymous data about user activity and how they arrived at the site. Analytical cookies are sent from the site itself.

    Cookie Consent

    This site, according to current regulations, is not required to request consent for technical and analytical cookies.

    For all other types of cookies, consent can be given by the User through one or more of the following methods:

    1. Through specific configurations of the browser used or the relevant computer programs used to navigate the pages comprising the site
    2. By changing the settings in the use of third-party services

    Both of these solutions could prevent the user from using or viewing parts of the site.
